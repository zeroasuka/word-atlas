# 學習模型 / Learning model

## 每日旅程

- **複習**：所有到期的詞（FSRS 計算的 `due` 已過）。
- **新詞**：每天上限可設（預設 10），從學習路線中你的起點難度開始取未學過的詞。
- 順序：先複習，再以 5 個為一組學新詞：先「初見」認識 5 個詞，再打亂順序回憶這 5 個詞。

## 題型

| 題型 | 適用 | 說明 |
| --- | --- | --- |
| 選義 | 新詞、記憶弱 | 看英文選中文，干擾項詞性相同 |
| 看圖補句 | 新詞、記憶弱 | 插畫 + 挖空例句，選英文詞，干擾項拼寫相近 |
| 聽音辨詞 | 各階段 | 只聽發音選詞 |
| 拼寫 | 穩定度較高 | 看圖和釋義拼寫，可以逐字母提示（提示後最多計 Hard） |

## 評分與 FSRS

每個詞在一輪中只有**第一次作答**更新記憶（ts-fsrs，FSRS-6，預設目標記憶率 90%）：

- 答錯 → Again
- 答對但慢、或用了提示 → Hard
- 答對 → Good；拼寫又快又對 → Easy

答錯的詞會在幾題之後換一種題型再練一次（最多兩次），重試不再評分，也不計入正確率。

「已掌握」= FSRS 複習狀態且記憶穩定度 ≥ 21 天。

## 打字練習

打字只訓練輸出，不改變記憶狀態。WPM 按每 5 個正確字元計 1 詞。
